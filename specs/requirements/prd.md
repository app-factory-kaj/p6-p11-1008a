# Greeter

## Problem Statement

Someone who wants to show or try a friendly, personalized greeting has no quick way to do it without writing a one-off script or page each time.

## Solution

A small web app with a form: the user signs in, types a name, presses Greet, and sees a greeting for that name appear below the form.

## Actors

- User — signs in via SSO and enters a name to receive a personalized greeting.

## Features

- F1 [Greet](features/F1-greet.md)

See [Product-wide](product-wide.md).

## Out of Scope

- A history or log of past greetings.
- Multiple languages or customizable greeting wording.
- Any persistence of names or greetings across sessions.
